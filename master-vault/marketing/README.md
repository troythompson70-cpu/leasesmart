# Marketing vault mirror

Microsoft 365 is the system of record for TGT marketing and business development.

This folder mirrors execution artifacts only. If docs diverge, prefer:

`TGT BUSINESS → MARKETING → 2026 MARKETING COMMAND CENTER`

## Subfolders

| Folder | Mirrors |
|--------|---------|
| `social-ops/` | Content calendar / social platform status |
| `biz-dev/` | **Deal / Opportunity Ledger** (BD, creator, NFR, sponsorship, MDF) |

Do not store passwords, tokens, or secrets here.
Do not create a second CRM outside this Command Center structure.
